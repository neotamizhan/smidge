# Trades

Converts millimetres to feet, inches, and a fractional inch via `mmToFtInFrac`.

- Input: millimetres.
- Output: ft, in, and a fraction with a selectable denominator.

A specialist calculator separate from the general
[category system](/features/general-converter.md); output rendered by
[fmt](/components/format.md).
