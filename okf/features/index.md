# Features

# General

- [General converter](/features/general-converter.md) — the home-screen path for
  length, mass, volume, area, speed, time, data, pressure, and energy.
- [Pins](/features/pins.md) — pinned quick conversions.

# Specialist calculators

Specialist screens are deliberately separate from the general category system
because they need domain-specific data, formatting, or interpretation.

- [Cooking](/features/cooking.md) — density-aware ingredient conversions.
- [Medical](/features/medical.md) — glucose, HbA1c, cholesterol, creatinine, triglycerides.
- [Trades](/features/trades.md) — millimetres to feet/inches/fractions.
- [Currency](/features/currency.md) — static snapshot rates.

All paths flow through the formatter — see [format](/components/format.md).
